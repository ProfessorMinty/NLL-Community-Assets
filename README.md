# Northern Lights Labs Community Assets

Public repository for Northern Lights Labs community-facing and reusable reference assets that Arctic has deliberately approved for public storage.

## Repository boundary

This repository may contain public images and related lightweight provenance notes intended for community pages, demonstrations, shared references, or other approved public uses.

It is not:

- a private canonical-asset vault;
- a product source-code repository;
- the Northern Lights Labs documentation vault;
- a storage location for unreleased character masters or private references;
- a place for credentials, databases, private archives, or user content.

Canonical project reasoning, decisions, current state, private references, and cross-project history remain in:

`ProfessorMinty/ProjectDocumentation`

## Rights and provenance

Public visibility does not create a blanket license or prove unrestricted reuse rights.

Before an asset is reused or redistributed, confirm any applicable per-asset record covering:

- creator or source;
- generation or editing history when relevant;
- intended public use;
- required credit;
- third-party material or references;
- redistribution permission;
- approved derivative use.

When no explicit per-asset license or permission record exists, do not assume rights beyond viewing the asset in this repository.

## Contribution rule

Add only assets deliberately approved for public exposure. Keep private, unfinished, sensitive, or canonically restricted material in its approved private location instead.
